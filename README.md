# Stock Portfolio Tracker

A simple Python-based Stock Portfolio Tracker developed as part of the CodeAlpha Python Programming Internship.

## Features

- Display available stocks
- Enter stock symbol and quantity
- Calculate individual stock investment
- Add multiple stocks to portfolio
- Calculate total portfolio investment
- Save portfolio details to CSV file

## Technologies Used

- Python
- CSV File Handling
- Dictionaries
- Lists
- Loops
- Functions
- Conditional Statements

## How to Run

1. Install Python.
2. Open the project folder.
3. Run the following command:

```bash
python stock_tracker.py
